# Provider logos

The marks beside each provider on the landing page, inlined by `build.mjs`. Each belongs to its company and is
shown only to name the provider Whittle connects to.

| File | Mark | From |
|---|---|---|
| `openai.svg` | OpenAI | [LobeHub Icons](https://github.com/lobehub/lobe-icons) 1.95.1 (MIT), `icons/openai.svg` |
| `openrouter.svg` | OpenRouter | [Simple Icons](https://github.com/simple-icons/simple-icons) 16.34.0 (CC0), `icons/openrouter.svg` |
| `claude-code.svg` | Claude Code | [LobeHub Icons](https://github.com/lobehub/lobe-icons) 1.95.1 (MIT), `icons/claudecode-color.svg` |

Single-colour marks use `currentColor`, so they follow the page's ink.
