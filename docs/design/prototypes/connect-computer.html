What changes

The beaver says how it's goingNot connected: the beaver looks up and flicks an ear, as on the Linux page. Connecting: it gnaws, and the ground line runs. If it fails, the status turns red and the note under Connect says what to check.
Three numbered stepsTurn on Use from your computer, open the tunnel, paste the token. Each step ticks once it's done here: the address typed, the token pasted.
A tunnel that stays openToday one command does both: ssh -L … cat token prints the token and closes, so the tunnel goes with it. Now the tunnel is its own command, with -N so it stays open, and reading the token is another.
The address, onceThe phone shows its Wi-Fi address on the Linux page. Type it once here and it fills both commands. The link address (ws://127.0.0.1:8790/…) is a detail, so it moves to a small line under Connect.
