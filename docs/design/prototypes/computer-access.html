Use the Linux workspace from your computer

The phone does the running; your computer does the typing. One new section on the Linux workspace screen turns on an SSH server inside the phone's Ubuntu. From any computer on the same Wi-Fi you get a terminal, your projects, VS Code or Cursor over Remote-SSH, and the phone's dev servers. No new screens: the section reuses Settings rows, and adding a computer uses the add-connection sheet.

  • Off until you turn it onNothing listens on the network until you switch it on, and it switches itself off when you leave Wi-Fi.
  • Only computers you addSign-in is by key, never a password. You paste the computer's public key once; Remove takes it back.
  • Wi-Fi onlyIt listens on the phone's Wi-Fi address, not on mobile data.
  • Your shell, not the agent'sAn SSH session is you at the keyboard, like the Linux terminal. Whittle's agent can't use it and doesn't see it.

What it's for, on the computer

A terminalCopy the row's command: ssh -p 8022 root@192.168.1.23. You land in the same Ubuntu Whittle uses, with its projects in /workspace.
VS Code or CursorRemote-SSH › Connect to Host, with the same address. Edit the phone's projects with the computer's editor; servers you start get forwarded automatically.
Dev serversA server Whittle runs on the phone, say Vite on 5173, opens on the computer with ssh -p 8022 -L 5173:localhost:5173 root@192.168.1.23, then localhost:5173.
Filesscp and sftp work too, so copying a project in or a build out is one command.

Checked on the emulator

OpenSSH runs under prootsshd started in the phone's Ubuntu 24.04 (aarch64) once its /run/sshd folder existed, and listened on 8022.
Login, terminal, tunnelFrom this Mac (through an adb port forward): key login in 0.3 s, a real terminal (/dev/pts/1), the workspace with git and Node, and a server on the phone reached through ssh -L.
Install leanA plain apt install openssh-server pulled in 66 packages, Python included. The build installs it without recommends.
Not checked yetVS Code's Remote-SSH server running under proot, and reaching the phone's real Wi-Fi address (the emulator is behind its own network). Both get checked on a real phone before merging.
